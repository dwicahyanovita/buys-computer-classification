# **Klasifikasi Pelanggan yang Akan Membeli Komputer**  

Proyek ini menggunakan algoritma **Decision Tree (ID3)** untuk mengklasifikasikan pelanggan yang berpotensi membeli komputer berdasarkan **usia, pendapatan, jenis pekerjaan, dan kredit rating**.  

## **🛠 Teknologi yang Digunakan**  
- **Python** (pandas, numpy, scikit-learn)  
- **Decision Tree (ID3 Algorithm)**  
- **Jupyter Notebook / Google Colab**  

## **📌 Atribut yang Digunakan**  
1. **Usia** (<=30, 30-40, >40)  
2. **Pendapatan** (High, Medium, Low)  
3. **Jenis Pekerjaan** (Student, NonStudent)  
4. **Kredit Rating** (Fair, Excellent)  

## **🚀 Cara Menggunakan**  
### **1. Clone Repository**  
```bash
git clone https://github.com/dwicahyanovita/buys-computer-classification.git
cd buys-computer-classification
```

### **2. Install Dependencies**  
```bash
pip install pandas numpy scikit-learn
```

### **3. Jalankan Script**  
- Unggah dataset yang tersedia (`DataBuysComputer.xlsx`).  
- Jalankan program untuk membangun model decision tree.  
- Gunakan fitur testing untuk mencoba data uji sendiri.
